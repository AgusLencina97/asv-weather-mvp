# ASV Weather · Frontend

Aplicación Angular 22 de la prueba. Las instrucciones completas de ejecución y la descripción de la arquitectura están en el [README principal](../README.md).

## Scripts

| Comando | Descripción |
|---|---|
| `npm start` | Servidor de desarrollo en <http://localhost:4200>, con proxy de `/api` al backend en el puerto 8080 |
| `npm test` | Tests unitarios con Vitest |
| `npm run test:watch` | Tests en modo observación |
| `npm run test:coverage` | Tests con informe de cobertura (`coverage/`) |
| `npm run build` | Build de producción en `dist/` |
